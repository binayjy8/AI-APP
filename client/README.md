# 📄 Document Q&A Assistant

A full-stack AI app that answers questions grounded strictly in a document you provide — built to avoid hallucination by design, not just prompt luck.

## What it does

Paste any text document, ask a question about it, and get an answer generated by an LLM using *only* that document as context. If the answer isn't in the document, the app says so instead of guessing.

## Why I built it this way

- **Grounded answers over free generation** — the prompt explicitly instructs the model to answer only from the provided document and admit when it doesn't know, reducing hallucination risk.
- **API key stays server-side** — the React frontend never talks to the AI provider directly; it calls my own Express backend, which holds the key. This is the correct security pattern for any production AI app.
- **Clear error handling** — both frontend and backend handle failure states (network errors, missing fields, API errors) instead of failing silently.

## Tech stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **AI Model:** Google Gemini API (gemini-3.6-flash)

## How it works

1. User pastes a document and types a question in the React form
2. Frontend sends `POST /api/ask` with `{ document, question }` to the Express backend
3. Backend builds a prompt combining instructions + the document + the question
4. Backend calls the Gemini API and returns the answer as JSON
5. Frontend displays the answer

## Running it locally

**Backend:**
\`\`\`bash
npm install
node server.js
\`\`\`

**Frontend (in a separate terminal):**
\`\`\`bash
cd client
npm install
npm start
\`\`\`

You'll need a free Gemini API key from [aistudio.google.com](https://aistudio.google.com) — add it to a `.env` file:
\`\`\`
GEMINI_API_KEY=your-key-here
\`\`\`
